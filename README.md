# Inset Maps (@InsetMaps)

Kênh Shorts tiếng Anh 9:16 cho khán giả Mỹ, Canada, Anh: mỗi video giải thích một tin hoặc một sự thật địa chính trị
bằng một tấm bản đồ. Câu chữ ký: *"The headline changes. The map doesn't."* Dựng bằng Remotion 4.0.532.

## Bắt đầu

```bash
npm ci
```

```bash
npm run dev
```

Tạo `gemini_key.txt` (mỗi dòng một key, không commit) rồi kiểm: `npm run tts:check`.

- `Map/00_he-thong/01_CHANNEL-BIBLE.md`: luật kênh (nguồn sự thật duy nhất).
- `Map/phan-tich-doi-thu/`: phân tích đối thủ (Cartogram Earth).
- `AGENTS.md`: cách làm việc, lệnh, cấu trúc.
